# MafiaNext — Telegram-бот + веб-игра

Настольная «Мафия» в двух видах с общей базой данных:

- **@MafiaNextBot** — Telegram-бот (`mafia_bot.py`).
- **MafiaNext Web** — та же игра на сайте, для тех, кто играет с компьютера (или телефона) и у кого может не быть Telegram. Каждый играет со своего устройства: тайные роли, ночные ходы, голосование и дуэли при ничьей — у каждого на своём экране. Ведущий управляет игрой со своего (`web_server.py` + `web/index.html`).

Веб-сервер использует код самого бота, поэтому правила, роли, порядок ночи, истории и очки — одни и те же. Комнаты и партии на сайте и в Telegram раздельные.

**Аккаунты.** На сайте входят по логину и паролю или играют как гость. Кто играет и в боте, пишет боту `/web`, вводит код на сайте — и получает **один аккаунт**: общие ник, очки и история.

## Файлы

| Файл | Назначение |
|---|---|
| `mafia_bot.py`, `texts.py` | Бот и все тексты (шесть языков). Здесь же команда `/web`, которая присылает коды для сайта. Веб-версия использует оба файла |
| `web_server.py` | Сервер веб-игры: комнаты, ход игры, вход, обновления по WebSocket |
| `web/index.html` | Многопользовательское веб-приложение (его отдаёт `web_server.py`) |
| `web/offline.html` | Версия «для одного телефона», работает без сервера |
| `deploy/mafiaweb.service` | Служба systemd для веб-сервера |
| `deploy/Caddyfile` | Настройка HTTPS-прокси (Caddy сам получает сертификат) |
| `.github/workflows/deploy.yml` | Автодеплой: каждый push в `main` обновляет сервер |
| `requirements.txt` | Пакеты Python |
| `.env`, `mafia.db` | Секреты и данные. **Только на сервере, никогда в Git** |

## Как устроена веб-игра

- **Вход:** логин и пароль или гость (просто ник; профиль живёт в этом браузере, его можно сохранить позже, задав логин и пароль в профиле).
- **«Есть Telegram»:** напишите боту `/web`, введите на сайте код из 6 цифр (действует 10 минут, срабатывает один раз), придумайте логин и пароль. Тем же способом потом сбрасывается забытый пароль. Аккаунт сайта можно связать и из профиля: его история переедет в телеграм-аккаунт.
- **Админ** (только владелец, `HOST_ID`, после связки своего Telegram): поиск аккаунтов и сброс пароля на временный.
- **Таблица лидеров:** все, кто играл на сайте, с очками за все их игры.
- **Раскладка:** на компьютере две колонки (действия слева; история, игроки и состав справа), на телефоне одна.
- **Комнаты:** создайте комнату и отправьте ссылку-приглашение (`https://ваш-домен/?room=3`). Создатель становится ведущим.
- **Настройки ведущего** — те же, что в боте (и общие с ним), плюс одна только для сайта:
  - **Ночные ходы:** *через ведущего* (классика: игроки показывают жестами, ведущий отмечает) или *со своих устройств* (каждая роль выбирает на своём экране; ведущий видит ✓, когда выбор сделан, и может его поправить).
  - **Голосование:** *через ведущего* или *со своих устройств* (тайные бюллетени), как в боте.
- **Игроки** видят свою карточку роли (скрыта, пока не нажать), личные сообщения (результаты детектива и адвоката, если включены, «вас убили», переход оборотня в мафию), бюллетени, дуэли «камень, ножницы, бумага», бросок кубика и историю, когда ведущий её покажет.
- Партии переживают перезапуск сервера и деплой: состояние комнаты сохраняется после каждого действия.
- Сыгранные на сайте партии записываются в те же таблицы `games` / `game_players`, что и партии бота.

## Первая настройка сервера

Всё делается на той же Oracle VM (`158.101.99.123`), рядом с ботом. Команды запускайте в Cloud Shell или на сервере, как указано.

### 1. Бесплатный домен (DuckDNS)

Пароли должны передаваться по HTTPS, а для HTTPS нужен домен.

1. Откройте [duckdns.org](https://www.duckdns.org) и войдите (через GitHub или Google).
2. Добавьте поддомен, например `mafianext` → `mafianext.duckdns.org`.
3. В поле **current ip** введите `158.101.99.123` и нажмите **update ip**.

### 2. Откройте порты 80 и 443

**В консоли Oracle Cloud:** Networking → Virtual cloud networks → ваша VCN → ваша подсеть → *Default Security List* → **Add Ingress Rules**: Source CIDR `0.0.0.0/0`, IP protocol TCP, destination port range `80,443`.

**На сервере** (в образе Ubuntu от Oracle порты закрыты ещё и внутренним файрволом):

```bash
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 80 -j ACCEPT
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 443 -j ACCEPT
sudo netfilter-persistent save
```

### 3. Установите Caddy (HTTPS)

```bash
sudo apt install -y debian-keyring debian-archive-keyring apt-transport-https curl
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | sudo gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' | sudo tee /etc/apt/sources.list.d/caddy-stable.list
sudo apt update && sudo apt install -y caddy
```

### 4. Выложите код на GitHub

1. Создайте репозиторий на github.com. Публичный подойдёт: секреты остаются в `.env` на сервере. Для приватного см. раздел *Приватный репозиторий* ниже.
2. **Add file → Upload files** и перетащите всё из этой папки.
3. Папка `.github` на многих компьютерах скрыта и может не загрузиться. Если в репозитории нет `.github/workflows/deploy.yml`, создайте его: **Add file → Create new file**, в имени наберите `.github/workflows/deploy.yml` и вставьте содержимое файла.

### 5. Превратите `~/mafia` на сервере в копию репозитория

Делается один раз, дальше сервер обновляется с GitHub сам. На сервере (`ubuntu@instance-...`):

```bash
cd ~/mafia
mkdir -p ~/backup && cp *.py .env mafia.db ~/backup/
rm -f mafia_bot.py texts.py
git init -b main
git remote add origin https://github.com/ВАШ-ЛОГИН/ВАШ-РЕПОЗИТОРИЙ.git
git fetch origin main
git reset --hard origin/main
./venv/bin/pip install -r requirements.txt
```

`.env` и `mafia.db` не пострадают: Git их игнорирует.

### 6. Запустите веб-сервер

```bash
sudo cp ~/mafia/deploy/mafiaweb.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now mafiaweb
sudo systemctl restart mafiabot
sudo systemctl status mafiaweb --no-pager
```

Затем укажите Caddy ваш домен:

```bash
sed "s/YOUR-NAME.duckdns.org/mafianext.duckdns.org/" ~/mafia/deploy/Caddyfile | sudo tee /etc/caddy/Caddyfile
sudo systemctl reload caddy
```

Откройте `https://mafianext.duckdns.org` — игра должна загрузиться. Первый запуск может занять минуту, пока Caddy получает сертификат.

### 7. Сообщите боту адрес сайта

Добавьте строку в `~/mafia/.env` и перезапустите бота, чтобы `/web` показывал ссылку:

```bash
echo "WEB_URL=https://mafianext.duckdns.org" >> ~/mafia/.env
sudo systemctl restart mafiabot mafiaweb
```

Затем свяжите свой Telegram: напишите боту `/web`, откройте сайт → **Есть Telegram**, введите код, придумайте логин и пароль. Ваш аккаунт станет админом сайта (Профиль → Админ).

### 8. Подключите автодеплой с GitHub

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**, три раза:

| Имя | Значение |
|---|---|
| `SSH_HOST` | `158.101.99.123` |
| `SSH_USER` | `ubuntu` |
| `SSH_KEY` | всё содержимое `oracle.key` (в Cloud Shell: `cat oracle.key`, скопируйте целиком, вместе со строками `BEGIN` и `END`) |

Проверка: **Actions → Deploy to Oracle VM → Run workflow**. Зелёная галочка — сервер забрал код и перезапустил обе службы.

## Обычная работа

Отредактируйте файл на GitHub (значок карандаша) или загрузите новую версию → **Commit**. GitHub Actions за минуту всё развернёт: заберёт код, установит пакеты и перезапустит бота и веб-сервер. Идущие партии продолжатся после перезапуска.

Старая процедура через Cloud Shell (`scp` + `ssh` + `systemctl restart`) больше не нужна. И не правьте файлы прямо на сервере: следующий деплой их перезапишет.

Логи на сервере:

```bash
journalctl -u mafiaweb -n 50 --no-pager
journalctl -u mafiabot -n 50 --no-pager
```

## Если что-то не так

- **Сайт не открывается:** проверьте, что DuckDNS указывает на правильный IP, сделаны оба шага с портами (консоль *и* `iptables`), а `sudo systemctl status caddy mafiaweb --no-pager` — зелёный.
- **Код из `/web` не принимается:** код действует 10 минут и срабатывает один раз — напишите `/web` снова. Если бот вообще не знает `/web`, на сервере старая версия (проверьте деплой).
- **Кто-то забыл пароль:** с Telegram — пишет `/web` и задаёт новый. Без Telegram — вы сбрасываете его в Профиль → Админ и передаёте временный пароль.
- **Деплой падает на `git fetch`:** папка на сервере ещё не копия репозитория (шаг 5) или репозиторий приватный (см. ниже).
- **Деплой падает на SSH:** в секрете `SSH_KEY` должен быть весь ключ, включая первую и последнюю строки.
- **На сайте «Нет связи — переподключаемся…»:** веб-сервер перезапускается (деплой) или остановлен. Смотрите `journalctl -u mafiaweb`.

## Приватный репозиторий

Если репозиторий приватный, серверу нужен доступ на чтение:

```bash
ssh-keygen -t ed25519 -f ~/.ssh/github_deploy -N ""
cat ~/.ssh/github_deploy.pub
printf "Host github.com\n  IdentityFile ~/.ssh/github_deploy\n" >> ~/.ssh/config
cd ~/mafia && git remote set-url origin git@github.com:ВАШ-ЛОГИН/ВАШ-РЕПОЗИТОРИЙ.git
```

Вставьте напечатанный ключ в репозитории: **Settings → Deploy keys → Add deploy key** (только чтение). Затем один раз выполните `git fetch origin main` и ответьте `yes`.

## Полезно знать

- **Пароли** хранятся только в виде хешей scrypt. После 5 неверных попыток логин блокируется на 10 минут (сброс пароля снимает блокировку).
- **Языки:** на сайте все шесть языков бота. Игровые тексты (роли, истории, кнопки из `texts.py`) переведены; немногие тексты только для сайта (вход, аккаунты) и сообщение бота `/web` для татарского, казахского, кыргызского и башкирского пока на русском. Названия команды `/web` в меню на этих четырёх языках — мой перевод, проверьте его, пожалуйста.
- **Настройки общие с ботом** (у связанных аккаунтов), но бот держит свою копию в памяти: изменение на сайте дойдёт до бота после его перезапуска (каждый деплой его перезапускает). Кроме того, бот при сохранении своих настроек теряет настройку «Ночные ходы», которой у него нет, — проверяйте её перед веб-партией.
- **Данные сайта** лежат в той же `mafia.db`, в таблицах, которые бот не использует: `web_accounts`, `web_guests` (профили только для сайта), `web_rooms`, `web_games`, `link_codes` (общая с `/web`).
- VM Micro с 1 ГБ спокойно тянет бота, веб-сервер и Caddy одновременно, с запасом на несколько десятков игроков.
